## 二、通用合規與技術規範

### 合規紅線（每幅必守）

1. 人物僅剪影／背影／遠景；禁止可辨認真人（領導、同事、明星、客戶）。
2. 可畫竹節高樓與維港天際線；**不可**畫中銀標誌、銀行卡、App 截圖、客戶／內部資料。
3. 國旗、區旗須完整正向、莊重；不作地氈、破損、扭曲、Fashion 道具。
4. 不抄襲 1997 交接等著名新聞照片構圖；不使用他人 AI 作品改圖。
5. 中文大字、作品名、鈐印留給後期 ≤10% 排版；不交給模型亂寫漢字。
6. AI 生成占比 ≥90%；後期僅限：色彩校正、構圖裁切、瑕疵修復、文字排版添加。

### 技術規格

- 長邊 ≥3000px，≥300DPI，JPG/PNG，≤20MB
- 橫幅建議 16:9 或 3:2；水墨（06）用 **3:4 直幅**
- 生成後用 Topaz Gigapixel / Magnific 放大
- 檔名：`姓名_作品名`（例：`陳大文_節節高昇香江竹韻`）

### 投稿資料清單（每幅）

1. 作品圖片  
2. 作品名稱  
3. 簡短創作理念（下文已備好，可微調）  
4. 所用 AI 工具  
5. 核心提示詞  

### 推薦工具組合

- **主生成**：Midjourney v6/v7 或 Flux Pro（寫實／光感）  
- **水墨**：Midjourney + `--stylize` 中高，或 Flux 搭配水墨風格描述  
- **放大**：Topaz Gigapixel / Magnific  
- **後期**：Lightroom／Photoshop（校色、裁切、去瑕疵、鈐印）

### 01｜節節高昇·香江竹韻 【建議投稿】

| 項目 | 內容 |
|------|------|
| **官方方向** | 香港發展（含蓄中銀語境） |
| **畫幅** | 16:9 橫幅 |
| **建議工具** | Midjourney / Flux Pro + Topaz 放大 + LR 校色 |

#### 畫面詳述

國慶黎明，維港水平如鏡，霧氣將散未散。一棟竹節造型的摩天樓自水面「生長」而起——只取竹節分段的建築比例與幾何韻律，**不出現任何商標、行名或標誌**。每一節樓體透出一層暖金內光，如竹節向上的年輪；頂節綻成一朵巨大的紫荊光花，花瓣由建築玻璃與晨光折射而成。對岸城市仍在沉睡的藍灰之中，唯有這一柱光在賀歲。遠空一顆含蓄的金色晨星，**不作五星排列**，避免標語感。近景可有極淡的渡輪剪影，人不入鏡。

#### 創作理念（投稿用，約 110 字）

竹有節，城有志。畫面以竹節高樓自維港水面節節向上，寓意香江與家國同向生長；頂節綻放的紫荊光花，是國慶的賀禮，也是城市對未來的承諾。不以旗海鋪陳，而以光與建築寫「發展」——穩健如竹，明亮如晨。本作以 AI 為筆，將香港天際線最富象徵的形態轉化為可感的節慶意象，是為「智繪香江」。

#### 為何能贏

內部評審可讀到「中銀／節節高／香江」而不覺得是月曆廣告；外部評審看到的是建築隱喻。全場極少人會這樣處理竹節樓，避開維港煙花紅海。

#### 核心提示詞

**中文：**

```
國慶黎明，維多利亞港水平如鏡，一棟竹節分段造型的摩天樓自水面生長升起，
每一節透出暖金內光，頂部綻放巨大紫荊光花，對岸城市藍灰沉睡，
遠空一顆金色晨星，電影感寫實，建築攝影，85mm，無標誌，無文字，無人物面孔
```

**英文（主用）：**

```
Cinematic dawn over Victoria Harbour, mirror-calm water, a bamboo-segment skyscraper
of luminous gold light rising from the harbour as if growing upward, each segment glowing
warmly from within, a giant bauhinia bloom of refracted gold light at the crown,
opposite shore still in blue-grey sleep, one soft golden morning star in the sky,
architectural photography, 85mm lens, volumetric mist, no logos, no trademarks,
no text, no readable faces, photoreal, masterpiece lighting --ar 16:9
```

#### 後期說明（≤10%）

1. 校色：抬高金色、壓低對岸藍灰，強化黎明對比  
2. 裁切：確保竹節樓佔畫面垂直主導，紫荊光花完整  
3. 去瑕疵：玻璃亂反射、水面偽影  
4. 可選：右下角極小鈐印「智繪香江」（勿遮主體）

#### 合規點

- 竹節樓＝建築形態致敬，非品牌再現  
- 無五星旗海、無行徽  
- 無人臉

### 02｜智脈香江·星河同慶 【建議投稿】

| 項目 | 內容 |
|------|------|
| **官方方向** | 金融科技 + 賽名「智繪」入畫 |
| **畫幅** | 16:9 橫幅 |
| **建議工具** | Midjourney / Flux（半寫實光感） + Topaz |

#### 畫面詳述

俯瞰港島與維港：街道、橋隧、海底隧道化作溫暖的**金色神經網絡／金融經絡**，脈搏與潮汐同步起伏。維港本身是一條流動的金色數據潮，但形態仍是海，不是電路板硬貼。夜空中五個光點連成含蓄五星——「星」由數據微粒組成，**不是貼國旗**。整色為繁榮的金紅與暖琥珀，**禁止賽博龐克、酸綠霓虹、陰雨廢土**。城市天際線可識，但不標樓名。

#### 創作理念（投稿用，約 120 字）

「智繪香江」不只是用 AI 作畫，更是把智慧寫進香江的肌理。俯瞰之夜，街道化作金色經絡，維港化作數據潮汐，星河中五點微光為國慶而亮。金融科技在此不是冰冷介面，而是城市得以同賀的脈搏。願以算法之筆，繪一幅溫暖、向上、可感的未來香江。

#### 為何能贏

把賽名「智繪」畫進主題；金融科技方向對銀行評審友善，又不賣產品；視覺與煙花照完全不同賽道。

#### 核心提示詞

**中文：**

```
俯瞰香港島與維多利亞港夜景，街道化作溫暖金色神經網絡經絡，
維港是金色數據潮汐，夜空五個數據光點連成含蓄五星，
繁榮金紅琥珀色調，半寫實光感插畫，非賽博龐克，無霓虹雨，無文字，無標誌
```

**英文（主用）：**

```
Aerial night view of Hong Kong Island and Victoria Harbour, city streets as warm golden
neural meridians and financial energy lines pulsing with the tide, harbour as a luminous
golden data current that still looks like water, five soft data-point stars forming a
subtle constellation in the sky, prosperous vermillion-gold and amber palette,
semi-realistic luminous illustration, hopeful and grand, NOT cyberpunk, no neon rain,
no dystopia, no text, no logos, no readable faces --ar 16:9
```

#### 後期說明（≤10%）

1. 統一金色經絡的亮度層級，避免花亂  
2. 微調五點星，確保含蓄、不喧賓奪主  
3. 裁去多餘邊緣雜光  
4. 可選鈐印

#### 合規點

- 五星＝光點星座，非旗幟鋪陳  
- 無區塊鏈圖標、無 App UI、無真實交易數據  
- 色調必須「慶」而不是「廢」

### 04｜獅子山曉·家國同心 【建議投稿】

| 項目 | 內容 |
|------|------|
| **官方方向** | 家國情懷 |
| **畫幅** | 3:2 或 16:9 橫幅 |
| **建議工具** | Midjourney / Flux 風景寫實 + Topaz |

#### 畫面詳述

獅子山山脊黎明：登山者僅為剪影與背影，**面容不可辨**。山下燈火將熄，九龍／港島輪廓可識。北面天際有一抹連綿的灣區晨曦（深港同亮的意象），一條**淡金光帶**自山脊緩緩流向北方——像家書、像問候，而不是邊界或鐵絲網。畫面沒有旗海，只有風、岩石、薄霧與日出。情緒是「同看一輪太陽」，不是集會海報。

#### 創作理念（投稿用，約 100 字）

同賀不一定在禮花下。獅子山頂，我們與無數背影一同迎來國慶的黎明；山下是熟悉的香江，天邊是相連的灣區晨光。淡金光帶自山脊向北，是家書也是同心。以 AI 繪此曉色，致敬獅子山精神——艱苦與希望並存，個人與家國同望。

#### 為何能贏

獅子山是香港人自己的家國語言，比硬貼紅旗更動人；情感票易進優異獎以上，展陳遠觀有氣勢。

#### 核心提示詞

**中文：**

```
獅子山山頂黎明，登山者剪影背影不可辨認面容，山下香港城市燈火將熄，
北面大灣區天際晨曦相連，淡金光帶自山脊流向北方，史詩風景，
空氣透視，金青黎明，無旗海，無文字，無人臉細節
```

**英文（主用）：**

```
Epic dawn on Lion Rock summit Hong Kong, hikers as dark unrecognizable silhouettes
seen from behind, city lights fading below, Greater Bay Area soft glow on the northern
horizon, a faint golden ribbon of light flowing from the ridge toward the north like a
letter home, atmospheric perspective, golden-cyan morning light, wind-blown grass,
no flags covering the frame, no readable faces, no text, no logos, photoreal landscape,
IMAX scale --ar 3:2
```

#### 後期說明（≤10%）

1. 壓暗剪影、提亮東方金邊  
2. 淡化金帶，避免像特效條  
3. 檢查人物無五官細節  
4. 可選鈐印

#### 合規點

- 無人臉、無真實同事  
- 金帶是詩意連結，不作地圖國界線  
- 不使用著名示威／新聞照片構圖

### 06｜水墨丹青·紫荊國慶 【建議投稿】

| 項目 | 內容 |
|------|------|
| **官方方向** | 文化傳承 |
| **畫幅** | **3:4 直幅**（卷軸感） |
| **建議工具** | Midjourney 當代水墨風 + 後期鈐印 |

#### 畫面詳述

直幅卷軸構圖：大片留白為天。淡墨寫維港山勢與岸線，筆觸寫意，參考吳冠中的建築線條與張大千的潑墨氣韻，**不是工筆滿密，不是動漫**。一點朱砂紅日／朱砂點醒畫面。紫荊以較細的工筆筆意從墨韻中綻出，花與墨交融。右下角預留空白，後期鈐朱文小印「智繪香江」或「同賀」。整體如可懸於展牆的「畫」，而非海報。

#### 創作理念（投稿用，約 100 字）

以墨寫城，以朱賀歲。算法接上筆墨，讓維港在留白中呼吸，讓紫荊自潑墨中開出。國慶不必鑼鼓喧天，亦可是一卷安靜的丹青——香江的山水與家國的節慶，在紙上同心。是為文化傳承，亦是智繪。

#### 為何能贏

展場一排寫實夜景中，直幅水墨會被專家評審記住；「智繪」對上「丹青」，文化傳承最正；形式差異即競爭力。

#### 核心提示詞

**中文：**

```
直幅中國當代水墨卷軸，淡墨維多利亞港與山勢，大片留白，朱砂紅日，
工筆紫荊自潑墨中綻放，吳冠中與張大千氣韻，寫意留白，非動漫，
非寫實照片天際線，無文字
```

**英文（主用）：**

```
Vertical contemporary Chinese ink wash scroll painting, Victoria Harbour and hills in
diluted black ink, large poetic negative space as sky, a vermillion cinnabar sun,
a gongbi-style bauhinia flower emerging from splashed ink, spirit of Wu Guanzhong
line and Zhang Daqian splash-ink, elegant literati atmosphere, NOT anime, NOT photoreal
skyline photo, no text, no seals in generation, museum quality --ar 3:4
```

#### 後期說明（≤10%）

1. 微調墨色層次與朱砂飽和  
2. 裁切成乾淨直幅，保留天頭留白  
3. **後期鈐印**「智繪香江」朱文小印（右下或左下）  
4. 可極淡加作品名豎排（可選）

#### 合規點

- 印與字算入 10% 後期  
- 不冒充某位已故畫家真跡署名  
- 紫荊造型勿抄具體版權插畫

### 03｜雙花倒影·維港之夜 【備選｜壯觀票】

|------|------|
| **官方方向** | 家國情懷 |

#### 畫面詳述

#### 創作理念（投稿用）

牡丹與紫荊，一為家國之花，一為香江之花。國慶之夜，雙花在維港上空同綻，又在水面合成一印——同賀，是兩朵花，也是同一枚心。以光為筆，以海為紙，智繪此夜。

#### 核心提示詞

**英文（主用）：**

```
Victoria Harbour National Day night, fireworks blooming as a giant peony and a giant
bauhinia side by side in the sky, their reflections overlapping on the water into one
luminous seal of light, recognizable Hong Kong skyline and Star Ferry silhouette,
small distant flags only, cinematic photoreal, spectacular but elegant, no text,
no logos, no readable faces --ar 16:9
```

#### 後期說明

強化「花形」輪廓；若仍像普通煙花，整幅不作投稿。

#### 合規點

旗小而正；不抄特定新聞攝影角度。

### 07｜潮汐金流·天星渡 【備選｜金融票】

| 項目 | 內容 |
|------|------|
| **官方方向** | 金融科技（詩意版） |
| **畫幅** | 16:9 |

#### 畫面詳述
